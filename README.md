# Insure With Gihan — PWA starter

This is a responsive, installable-web-app **prototype** for Android and iPhone.

## Preview
Open `index.html` in a browser or publish this folder to a static HTTPS host.

## Demo login
- Enter a Sri Lankan mobile number.
- The preview does not send SMS.
- Enter demo code `123456`.

## Important: not production-ready
This starter uses a front-end demo flow only. It has no real user accounts, SMS OTP, database, customer records, payment processing, notifications, or protected admin backend. Do not enter real customer, policy, identity, or payment information.

## Before real customer use
1. Set up a secure backend and database with per-customer access controls.
2. Connect a real OTP/SMS provider and rate limiting.
3. Build a separately authenticated admin portal with role-based access.
4. Store policy/payment data only from authorised records; keep payment status agent-verified as required.
5. Add audit logs, backups, privacy notice, consent and data-retention rules.
6. Obtain approval for any Sri Lanka Insurance Life name/logo and customer-facing representations. Do not imply this is an official insurer app unless authorised.
7. Configure the real WhatsApp Business support number and verified support workflows.
8. Test security, accessibility, and iOS/Android installation before launch.

## Free hosting
A static prototype can be hosted on a free static-hosting tier. Real SMS OTP, secure backend/database usage, a custom domain, and high-volume messaging may have costs or provider limits.
